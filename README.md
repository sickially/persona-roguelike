# Persona: Rogue Like (Nome provisório)

## Visão Geral
O site é um jogo baseado na franquia/spin-off **Shin Megami Tensei: Persona**, só que com elementos de jogos roguelike. Feito e pensado para jogar em navegadores, ou seja, tanto quem está no PC quanto quem está no celular terá uma experiência mínimamente parecida com os jogos de videogame.

## Como funciona?
Diferente dos jogos da franquia, esse jogo é completamente focado no combate. Pegue seu equipamento durante a exploração das dungeons, adquira level o suficiente para conseguir novas Personas, contrate novos companheiros de equipe e pense bem antes de agir.

A partir do momento que o jogo começa, o jogador terá três caminhos para começar a sua jornada:

- Mortality (Uma área baseada no Tartarus)
- Truth (Baseado nas dungeons do Midnight Channel)
- Rebellion (Baseado no mementos)

Todos os caminhos possuem o mesmo sistema de dificuldade. A escolha vai totalmente da preferência do jogador.

---

### Novo jogo

No início de cada caminho, o jogador será submetido a **cinco opções**. Sendo elas:

- Iniciar Exploração (Inicia a exploração na dungeon.)
- Gerenciar Equipe (Gerenciar o equipamento, sub-persona e status da equipe.)
- Gerenciar Inventário (Gerenciar itens obtidos durante a exploração. Podem ser vendidos.)
- Velvet Room (Fundir, registrar ou comprar Personas)
- Salvar Progresso (O progresso é salvo localmente no dispositivo do jogador.)
