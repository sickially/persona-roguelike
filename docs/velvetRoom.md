## Velvet Room
Com a implementação da API `megaten-database` (https://github.com/aqiu384/megaten-database), o Jogo contará com um sistema de Velvet Room similar a dos jogos de consoles, porém simples.

Sempre que o jogador termina uma luta com sucesso, existe uma pequena chance de uma das Shadows que ele esteve lutando, faça um contrato com ele. Assim, ocupando um slot na lista de Personas (8 Slots no máximo). O jogador poderá utilizar esses Personas adquiridos no campo de batalha, assim aumentando seu nível e ganhando novas skills, ou, poderá usa-los como receita na **Velvet Room** para conseguir personas mais fortes.

**IMPORTANTE LEMBRAR:** O jogador **NÃO PODE** fundir ou pegar personas de level **ACIMA DELE.**
